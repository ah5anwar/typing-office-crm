## প্রয়োজনীয়তা

- PHP **8.0 বা তার উপরে** (cPanel-এ MultiPHP Manager থেকে সিলেক্ট করো)
- MySQL 5.7+ / MariaDB 10.3+
- PHP এক্সটেনশন: `pdo_mysql`, `curl` (অথবা `allow_url_fopen`), `mbstring`
  → mbstring না থাকলেও চলবে, `core/compat.php` ফলব্যাক দেয়

Composer, Node.js, SSH — কোনোটাই লাগবে না।

## ইনস্টলেশন

**SQL ইমপোর্ট করতে হবে না** — ইনস্টলার নিজেই টেবিল বানিয়ে নেয়।

**১. ডাটাবেজ তৈরি**
cPanel → MySQL Databases → একটা **খালি** ডাটাবেজ ও ইউজার বানাও,
ইউজারকে ALL PRIVILEGES দাও। নাম-পাসওয়ার্ড টুকে রাখো।

**২. ফাইল আপলোড**
সব ফাইল `public_html/` (বা সাবডোমেইন ফোল্ডার) এ আপলোড করো।

**৩. ব্রাউজারে ইনস্টলার খোলো**

```
https://yourdomain/install/
```

পাঁচ ধাপ:

| ধাপ | কী হয় |
|---|---|
| ১. Server | PHP ভার্সন, এক্সটেনশন, ফোল্ডার পারমিশন পরীক্ষা |
| ২. Database | তোমার দেওয়া তথ্যে সংযোগ, **৩৪টি টেবিল অটো তৈরি** |
| ৩. Your account | মালিক অ্যাকাউন্ট (সবসময় সব অধিকার) |
| ৪. Business | নাম, ফোন, কারেন্সি, টাইমজোন, তোমার WhatsApp নম্বর |
| ৫. Finish | `config.local.php` লেখা হয়, `JWT_SECRET` নিজে তৈরি হয় |

`core/config.php` হাতে বদলাতে হবে না — ইনস্টলার `core/config.local.php`
বানিয়ে দেয়, আর ৬৪ অক্ষরের র‍্যান্ডম `JWT_SECRET` নিজেই তৈরি করে।

**৪. install ফোল্ডার মুছে ফেলো**
শেষ পাতার বাটনে চাপলে নিজেই মুছে যায়। না গেলে cPanel File Manager থেকে
`install/` ডিলিট করো। ইনস্টল শেষ হলে `core/install.lock` তৈরি হয়, তাই
কেউ দ্বিতীয়বার ইনস্টলার চালাতে পারবে না।

**৫. ক্রন**
cPanel → Cron Jobs → **একটাই** এন্ট্রি, প্রতি ৫ মিনিটে:

```
/usr/local/bin/php /home/USERNAME/public_html/cron/master.php
```

নতুন শিডিউল কাজ ভবিষ্যতে `cron_tasks` টেবিলে সারি হিসেবে যোগ হবে — নতুন cron এন্ট্রি লাগবে না।

> CLI cron না থাকলে ইনস্টলার যে `cron_key` বানিয়েছে সেটা দিয়ে
> `https://yourdomain/cron/master.php?key=...` URL cron হিসেবে দাও।
> কী-টা Settings-এ দেখা যাবে।

**আবার ইনস্টল করতে চাইলে:** `core/install.lock` মুছে `install/` ফোল্ডার
আবার আপলোড করো। স্কিমা `CREATE TABLE IF NOT EXISTS` ব্যবহার করে, তাই
পুরনো ডেটা নষ্ট হয় না।

## স্টাফ ও পারমিশন

`https://yourdomain/admin/#/staff` — স্টাফ যোগ করার সময় **প্রতিটি কাজে আলাদা টিক**।
রোল দুটি: **owner** (তুমি — সবসময় সব অধিকার) আর **staff** (শুধু যা টিক দেবে)।

চারটি পারমিশন `private` চিহ্নিত — এগুলো ভেবে দেবে:

| পারমিশন | না দিলে যা হয় |
|---|---|
| `costs.view` | তোমার খরচের দাম, লাভ, মার্জিন — কোথাও দেখাবে না। API থেকেও ফিল্ডগুলো বাদ যায়, শুধু UI-তে লুকানো নয় |
| `settings.manage` | সেটিংস, WhatsApp টোকেন, exchange rate — কিছুই না |
| `users.manage` | অন্য স্টাফ যোগ বা পারমিশন বদলাতে পারবে না |

মোছার অধিকার (`*.delete`) আলাদা টিক — সাধারণ স্টাফকে না দেওয়াই ভালো,
তাহলে সে এন্ট্রি করতে পারবে কিন্তু হিসাব মুছতে পারবে না।

**পাসওয়ার্ড রিসেট বা অ্যাকাউন্ট বন্ধ করলে** ওই ব্যক্তির সব ডিভাইস সাথে সাথে
লগআউট হয়ে যায় — চালু টোকেনও তৎক্ষণাৎ অকেজো হয়।

স্টাফ অ্যাকাউন্ট মুছে ফেলা হয় না, বন্ধ করা হয় — তার করা এন্ট্রি হিসাবেই থাকে,
আর `activity_log`-এ কে কী করেছে তা লেখা থাকে।

## মেসেজিং সেটআপ

`PATCH /api/v1/settings` অথবা অ্যাডমিন প্যানেল থেকে:

| সেটিং | কী দেবে |
|---|---|
| `wa_phone_number_id` | Meta Business → WhatsApp → API Setup |
| `wa_access_token` | Permanent System User token |
| `telegram_bot_token` | @BotFather থেকে |
| `self_whatsapp` | তোমার নিজের নম্বর (ডাইজেস্ট আসবে) |

**চ্যানেল ভেদে বাস্তবতা:**

- **WhatsApp** — ২৪ ঘণ্টার বাইরে পাঠাতে Meta-অনুমোদিত **template** লাগে।
  টেমপ্লেট অ্যাপ্রুভ করে তার নাম `message_templates.wa_template_name`-এ বসাও।
- **Telegram** — কাস্টমারকে একবার বটে `/start` চাপতে হবে, তারপর `telegram_chat_id` সেভ করো।
- **Messenger** — Meta শুধু কাস্টমারের মেসেজের ২৪ ঘণ্টার মধ্যে রিপ্লাই করতে দেয়।
  তাই এখানে অটো রিমাইন্ডার সম্ভব নয়; শুধু রিপ্লাই ও কপি-টেক্সট।

`POST /api/v1/settings/test-channel` দিয়ে সেটআপ ঠিক আছে কিনা পরীক্ষা করো।

## কারেন্সি — একটাই

Settings → **Money** → Currency। একবার ঠিক করলে সেবার দাম, ইনভয়েস, খরচ,
অ্যাকাউন্ট, রিপোর্ট — সব জায়গায় সেটাই। **দ্বিতীয় কোনো কারেন্সি কোথাও দেখাবে না**,
কোনো ফর্মে আর কারেন্সি বাছতে হবে না।

## কাজের তালিকা (Work list)

`#/work` — দুই দিক থেকে দেখা যায়:

- **From customers** — কাস্টমার যে কাজ দিয়েছে, লাইন ধরে। কোনটা বাকি, কোনটা শেষ,
  কোনটা সাপ্লায়ারকে দেওয়া
- **Given to suppliers** — তুমি কাকে কী দিয়েছ, কোনটা শেষ, কোনটা বিল হয়েছে

বাঁ পাশে কাস্টমার বা সাপ্লায়ার ভিত্তিক তালিকা — নাম চাপলে শুধু তার কাজ।
তালিকা থেকেই কাজ "Mark done" করা যায়।

## ডকুমেন্ট টাইপ ও কাস্টম ফিল্ড

Documents → **Document types** থেকে নিজে টাইপ বানাও, আর ঠিক করে দাও সেটা কী কী
তথ্য রাখবে। ছয় ধরনের উত্তর: লেখা, সংখ্যা, তারিখ, তালিকা থেকে পছন্দ, লম্বা লেখা,
হ্যাঁ/না। কোনটা বাধ্যতামূলক তাও বেছে নেওয়া যায়।

ওই টাইপের ডকুমেন্ট যোগ করলে ঠিক সেই প্রশ্নগুলোই ফর্মে আসে।

> কোনো ফিল্ড পরে মুছে দিলে **পুরনো ডকুমেন্টের উত্তর হারায় না** — ফিল্ডটা
> অবসর নেয়, নতুন ফর্মে আসে না, কিন্তু যেসব ডকুমেন্টে উত্তর ছিল সেখানে
> `retired` চিহ্ন দিয়ে দেখা যায়।

## ইনভয়েসের চেহারা

Settings → **Invoice design**:

- তিনটি প্রস্তুত ডিজাইন — Classic, Modern, Compact
- accent রং, কাগজের মাপ (A4/Letter)
- লোগো, স্বাক্ষর, একক, ব্যাংক তথ্য দেখাবে কিনা — আলাদা সুইচ
- ফুটারে নিজের লাইন
- **Preview** বাটনে নমুনা ইনভয়েস খুলে দেখা যায়, আসল ইনভয়েস ছোঁয়া ছাড়াই

চাইলে **নিজের HTML** লেখা যায়। ৩২টি প্লেসহোল্ডার আছে (`{{doc_no}}`,
`{{items}}`, `{{total}}` ...), ক্লিক করলেই বসে যায়। কাস্টমারের লেখা সব তথ্য
escape হয়ে যায়, তাই নামের ভেতর কোনো ট্যাগ থাকলেও পাতা ভাঙবে না।

## লোগো ও স্বাক্ষর

Settings → **Logo and signature** — ছবি আপলোড করো (PNG/JPG/WebP)। ইনভয়েসে
ছবিটা inline বসে, তাই প্রিন্টের সময় আলাদা করে লোড হয় না।


## ফাইল ও প্রমাণ

**যেকোনো কিছুর সাথে ফাইল রাখা যায়** — পাসপোর্ট, ভিসা, ট্রেড লাইসেন্স, ড্রাইভিং
লাইসেন্স, ইজারা, ভ্যাট সার্টিফিকেট; আবার টাকার এন্ট্রির প্রমাণও: বিকাশের
স্ক্রিনশট, ব্যাংক স্লিপ, সই করা রশিদ।

প্রতিটি ফাইলে দুটো আলাদা বাটন:

- **View** — ব্রাউজারে খুলে যায় (PDF ও ছবি), ডাউনলোড হয় না
- **Download** — কম্পিউটারে নেমে যায়

টাকা এন্ট্রি করার সাথে সাথেই প্রমাণ যোগ করার সুযোগ আসে। পরেও যোগ করা যায়।

ফাইল কখনো সরাসরি URL দিয়ে খোলা যায় না — প্রতিটি লিংক সই করা ও স্বল্পমেয়াদি।

## নগদ ও ব্যাংক

প্রতিটি জমা, খরচ ও সাপ্লায়ার পেমেন্টে **নগদ না ব্যাংক** তা লেখা থাকে। কীভাবে
পেয়েছ (বিকাশ, চেক, কার্ড) সেটা আলাদা — নগদ/ব্যাংক না বললে পদ্ধতি থেকেই ধরে নেয়।

`GET /reports/cash-bank` — কোন পথে কত ঢুকল, কত বেরোল।

## কাস্টমারের এক পাতা

`#/customers/{id}` — কাউকে ফোন করার আগে যে পাতাটা খুলবে:

- কত বকেয়া, কত জমা পড়েছে, কত অ্যাডভান্স হাতে আছে
- কোন কাজ বাকি, কার কাছে আছে, কবে দিতে হবে
- তার কোন কাগজের মেয়াদ কবে শেষ
- তার সব ফাইল — এক জায়গায়, View ও Download সহ
- পুরো লেনদেনের খতিয়ান আর শেষ পাঠানো মেসেজ

## ইনভয়েস থেকে কাজ

ইনভয়েস বানানোর সময় প্রতিটি লাইনে **"To do"** টিক আছে। টিক দেওয়া লাইনগুলো
কাজের তালিকায় যায়, বাকিগুলো শুধু বিল হয়। বিল দেওয়া আর কাজ শুরু করা আলাদা
সিদ্ধান্ত — আগে বিল দিয়ে পরে কাজ শুরু করতে পারো, বা শেষ হওয়া কাজের বিল দিতে পারো।


## অ্যাকাউন্ট — টাকা কোথায় আছে

`#/accounts` — এটাই সিস্টেমটাকে সত্যিকারের হিসাব ব্যবস্থা করে।

তুমি নিজে অ্যাকাউন্ট খুলবে: **অফিস ক্যাশ**, **সিটি ব্যাংক ৪৪১৭**, **বিকাশ মার্চেন্ট**।
প্রতিটির প্রারম্ভিক ব্যালেন্স দেবে — সেখান থেকে গোনা শুরু।

- প্রতিটি **জমা, খরচ, সাপ্লায়ার পেমেন্ট** কোন অ্যাকাউন্টে যাবে তা বেছে দেবে
- **Move money** — এক অ্যাকাউন্ট থেকে আরেকটায় (ব্যাংক থেকে ক্যাশ তোলা)
- **Add / take out** — মালিকের বিনিয়োগ, ব্যাংক চার্জ, যা কাস্টমার-সাপ্লায়ারের সাথে নয়
- **Statement** — ব্যাংক স্টেটমেন্টের মতো, চলতি ব্যালেন্সসহ

ড্যাশবোর্ডে সবসময় দেখাবে **হাতে কত টাকা** আর কোন অ্যাকাউন্টে কত।

> এন্ট্রি মুছে দিলে ক্যাশবুকের সংশ্লিষ্ট সারিও মুছে যায় — ব্যালেন্স কখনো ভুল হয় না।

## ইমেইল

Settings → **Email (SMTP)**। cPanel → Email Accounts → Connect Devices থেকে
host, port, username পাবে। Composer লাগে না — SMTP সরাসরি কথা বলে।
**Send a test email** দিয়ে যাচাই করে নিও।

ইমেইল চালু হলে WhatsApp ও Telegram-এর পাশে ইমেইলও একটা চ্যানেল হয়ে যায়।

## পাঠানো

- **ইনভয়েস / কোটেশন** — পাতার **Send** বাটন। WhatsApp, Telegram বা ইমেইল;
  গ্রাহক একটা লিংক পায় যা খুললেই ডকুমেন্ট
- **হিসাব** — কাস্টমার বা সাপ্লায়ারের পাতায় **Send statement**:
  কত বিল হয়েছে, কত জমা, কত বাকি, অ্যাডভান্স কত, কাজ কতটা বাকি
- পাঠানো ব্যর্থ হলেও লেখাটা ফেরত আসে, কপি করে হাতে পাঠাতে পারবে

## ডকুমেন্টের ফাইল

ডকুমেন্ট টাইপ বানানোর সময় ফিল্ডের ধরনে **File (PDF, photo)** বেছে নাও —
"পাসপোর্টের ছবির পাতা", "ভিসার কপি" আলাদা ফিল্ড হবে। ডকুমেন্ট যোগ করার
ফর্মেই ফাইল বাছবে, সেভ করলেই আপলোড হয়ে যাবে।

প্রতিটি ফাইলে **View** (ব্রাউজারে খোলে) আর **Download** (নেমে যায়) — আলাদা।



## ফাইল ও জায়গা

Settings → **Files and space** — কত ফাইল, কত জায়গা, আর কোন ফাইলগুলো মুছে
ফেলা রেকর্ডের।

রেকর্ড মুছলে তার ফাইল **সাথে সাথে মুছে যায় না** — ভুল করে মুছলে পাসপোর্টের
স্ক্যান যেন না হারায়। ওগুলো "অনাথ" হিসেবে আলাদা দেখায়; তুমি নিশ্চিত হলে
এক ক্লিকে পরিষ্কার করবে। বছরের পর বছর হোস্টিং ভরে যাওয়ার ভয় নেই।

> **টাকার এন্ট্রি সম্পাদনা:** তারিখ, মাধ্যম বা অ্যাকাউন্ট বদলালে ক্যাশবুক
> সাথে সাথে নতুন করে লেখা হয় — ব্যালেন্স কখনো ভুল থাকে না। তবে **জমার
> পরিমাণ বদলানো যায় না**, কারণ সেটা ইনভয়েসের বরাদ্দ ভেঙে দিত; ভুল হলে
> মুছে নতুন করে বসাও।

## অ্যাডমিন প্যানেল

`https://yourdomain/admin/` — ইংরেজি ইন্টারফেস, কোনো বিল্ড স্টেপ নেই।
সাধারণ HTML + CSS + ES module, তাই cPanel-এ শুধু আপলোড করলেই চলে।

উপরের **ledger strip**-এ সবসময় দেখাবে: কে কত টাকা দেবে, তুমি কত দেবে,
হাতে কত অ্যাডভান্স আছে। বাঁ পাশে **Official / Personal** ট্যাব —
চাপলেই পুরো সিস্টেম সেই বইয়ে চলে যায়।

সব টাকার অঙ্ক monospace ফন্টে, ডানে অ্যালাইন করা — কলাম মিলিয়ে পড়া যায়।
সবুজ = টাকা আসছে / শোধ হয়েছে, লাল = বাকি / দেনা।

## ফোল্ডার

```
admin/          অ্যাডমিন প্যানেল (HTML/CSS/JS, বিল্ড লাগে না)
file.php        সংযুক্ত ফাইল সার্ভ করে — ?view=1 হলে ব্রাউজারে খোলে,
                না হলে ডাউনলোড হয় (টোকেন ছাড়া খোলে না)
asset.php       লোগো ও স্বাক্ষর সার্ভ করে
api/v1/         REST API (ফ্রন্ট কন্ট্রোলার + ১১ কন্ট্রোলার)
core/           config, db, jwt, auth, validator, router, finance, messenger
cron/           master.php + tasks/ (৪টি টাস্ক)
print/          ইনভয়েস ও কোটেশনের প্রিন্ট পেজ
storage/        ডকুমেন্ট ফাইল (ওয়েব থেকে ব্লকড)
database.sql    সম্পূর্ণ স্কিমা — পরিবর্তন এই ফাইলেই করবে
install/        ইনস্টল উইজার্ড (ইনস্টলের পর ডিলিট)
```

## অ্যান্ড্রয়েড অ্যাপ
